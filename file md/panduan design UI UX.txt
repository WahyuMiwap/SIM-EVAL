Panduan design antarmuka:
Fondasi Design Token
Palet Warna Fungsional:

Primary (BNN Blue): #4361EE (tombol aksi utama, status fokus, tautan aktif).

Neutral Background: #F5F6FA (latar halaman), #FFFFFF (permukaan kartu dan modal).

Neutral Borders: #E4E6EF (garis pemisah sel tabel dan formulir).

Teks Utama: #111827 (judul dan teks kontras tinggi), #4B5563 (teks label sekunder).

Status Badges:

Sukses / Kategori Paham: Latar #F0FDF4, Teks #16A34A.

Peringatan / Cukup: Latar #FFFBEB, Teks #D97706.

Bahaya / Kurang: Latar #FEF2F2, Teks #DC2626.

Tipografi & Angka:

Headings: Plus Jakarta Sans (SemiBold / Bold).

Body UI: Inter (Regular / Medium).

Kolom Angka (Skor, Timer, Persentase): Wajib menggunakan kelas Tailwind tabular-nums agar karakter angka memiliki lebar seragam dan sejajar vertikal saat ditampilkan dalam tabel.

Sistem Spasi (8-Point Grid):

Pengaturan jarak margin dan padding berbasis kelipatan 8 piksel (8px, 16px, 24px, 32px).

Radius sudut: 6px untuk elemen input formulir, 10px untuk kontainer kartu, dan 20px untuk modal dialog.

Spesifikasi Halaman Detail Kegiatan & Meja Kerja Rekap
Header Informasi Kegiatan:

Memuat nama sekolah/lokasi, tanggal pelaksanaan, dan pil status kegiatan (Dijadwalkan, Berlangsung, Selesai).

Bilah aksi memuat dua tombol: Unduh Rekap Excel (sekunder) dan 📷 Buka Kamera Scanner (primer unggulan).

Struktur Tabel Interaktif Spreadsheet:

No (lebar 50px, perataan tengah).

Nama Siswa (lebar 280px, elemen input teks tanpa border dengan focus-ring halus saat aktif).

Pre-Test (lebar 110px, elemen input angka min="0" max="100", perataan tengah, tabular-nums).

Post-Test (lebar 110px, elemen input angka min="0" max="100", perataan tengah, tabular-nums).

N-Gain (lebar 110px, kolom nonaktif/read-only berisi nilai desimal kalkulasi otomatis).

Kategori (lebar 140px, lencana warna dinamis: Paham/Cukup/Kurang).

Aksi (lebar 60px, tombol ikon tempat sampah untuk menghapus baris).

Pola Navigasi Keyboard:

Menekan Enter pada kolom nilai memindahkan fokus input langsung ke baris peserta di bawahnya.

Menekan Tab menggeser kursor ke kolom nilai di sebelah kanannya (Pre-Test ke Post-Test).

Menekan tombol panah bawah ↓ pada baris terakhir otomatis memicu penambahan baris kosong baru.

Footer Ringkasan Tabel:

Baris kalkulasi statis yang menampilkan total peserta, rata-rata skor Pre-Test, rata-rata skor Post-Test, dan rata-rata persentase efektivitas N-Gain kelas.

Spesifikasi Modal Scanner OMR Layar Penuh
Overlay & Jendela Kamera:

Latar belakang menggunakan overlay gelap meredup (rgba(15, 23, 42, 0.85)) dengan efek blur latar (backdrop-filter: blur(4px)).

Jendela pemindai di tengah memuat garis bingkai bidik (scanning reticle) berwarna hijau untuk presisi penempatan lembar kertas A4.

Animasi garis laser vertikal berjalan naik-turun sebagai indikator aktifnya analisis citra.

Umpan Balik Pemindaian Beruntun (Continuous Scan):

Saat lembar kertas terdeteksi dan tanda silang (X) terbaca valid:

Garis bingkai bidik berkedip hijau selama 200 milidetik.

Sistem memutar suara beep pendek melalui Web Audio API.

Kartu indikator melayang di pojok layar menampilkan pop-up data ter-scan.

Sistem langsung bersiap memindai lembar berikutnya tanpa memerlukan interaksi klik mouse tambahan.

Fitur Penanganan Masalah (Fallback):

Tersedia tab beralih: Gunakan Kamera dan Unggah Foto Berkas (untuk mengunggah foto lembar jawaban jika webcam komputer kantor mengalami kendala resolusi).

Jika tanda silang terdeteksi samar, modal menampilkan pop-up verifikasi pilihan ganda manual sebelum nilai disimpan.

Spesifikasi Antarmuka Dasbor Operator Seluler (PWA Mobile)
Bilah Atas & Menu Hamburger:

Header atas sticky memuat tombol hamburger (☰) di kiri dan judul halaman aktif di tengah.

Menekan ikon hamburger membuka panel navigasi drawer (off-canvas) dari sisi kiri layar dengan transisi 200ms.

Tampilan Daftar Berbasis Kartu (Card View):

Tabel kegiatan pada layar ponsel dialihkan menjadi tumpukan kartu informasi vertikal.

Setiap kartu menampilkan nama lokasi sosialisasi, tanggal pelaksanaan, jumlah partisipan terdaftar, dan pil status warna.

Target sentuh tombol (touch target) memiliki dimensi minimal 44×44 piksel untuk memastikan kemudahan navigasi satu tangan.

Pedoman Aksesibilitas & Pencegahan Kesalahan (Error Prevention)
Validasi Nilai Real-Time: Pengetikan angka di luar rentang 0 s.d. 100 langsung mengubah garis batas input menjadi merah (#EF4444) dan mengembalikan nilai ke batas valid terdekat secara otomatis.

Proteksi Aksi Destruktif (FR-43): Penekanan tombol hapus kegiatan atau bank soal mewajibkan pengetikan ulang kata sandi pengguna aktif melalui modal otorisasi, disertai animasi getar (shake) jika sandi tidak cocok.

Kontras Teks: Seluruh elemen teks memenuhi ambang batas kontras rasio minimal 4.5:1 terhadap warna latarnya sesuai pedoman kepatuhan WCAG 2.1 AA.

2. Alur Sistem Berdasarkan Peran (Role-Based Flowchart)
A. Alur Super Admin
Fokus pada tata kelola hak akses dan akun operasional sistem.

B. Alur Staf / Operator & Anak Magang
Fokus pada manajemen data evaluasi, pemindaian kertas di kantor, dan pengunduhan laporan Diktari.

C. Alur Peserta Ujian (Khusus Engine B Digital PWA)
Pengerjaan langsung melalui peramban ponsel tanpa proses pembuatan akun.
